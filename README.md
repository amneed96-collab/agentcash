# ক্যাশ ম্যানেজার — GitHub Pages ডিপ্লয় গাইড

⚠️ **গুরুত্বপূর্ণ (এই আপডেটের জন্য)**: ব্যাকএন্ড এখন প্রতিটা বিভাগের জন্য
আলাদা শীটে (Cash, Expenditure, LoanGet, ClosingCash, Staff ইত্যাদি — কলাম
হেডারসহ) ডেটা রাখে, আগের মতো একটামাত্র "Data" শীটে না। এই ফিচার কাজ করতে
হলে **নতুন `Code.gs`** অবশ্যই আপনার Apps Script প্রজেক্টে পেস্ট করে নতুন
ভার্সন Deploy করতে হবে (নিচে "Apps Script রিডিপ্লয়" অংশ দেখুন)। শুধু
GitHub-এ এই ফাইল দুটো আপলোড করলেই যথেষ্ট না।

**ডেটা মাইগ্রেশন নোট**: নতুন শীট-ভিত্তিক কাঠামো আগের "Data" শীটের সাথে
সামঞ্জস্যপূর্ণ না। আগে এন্ট্রি করা ডেটা "Data" শীটেই থেকে যাবে, কিন্তু
অ্যাপ এখন থেকে নতুন আলাদা শীটগুলো পড়বে — অর্থাৎ পুরনো এন্ট্রি নতুন শীটে
স্বয়ংক্রিয়ভাবে আসবে না। প্রয়োজনে ম্যানুয়ালি আবার এন্ট্রি করে নিতে হবে।

এই ফোল্ডারে দুটো ফাইল আছে:
- `index.html`
- `bundle.min.js`

## Apps Script রিডিপ্লয় (আগে করুন)
1. Google Sheet খুলুন → Extensions → Apps Script
2. আগের সব কোড মুছে নতুন `Code.gs` এর পুরো কনটেন্ট পেস্ট করুন
3. Script Properties-এ `ACCESS_KEY` আগের মতোই থাকবে (পরিবর্তনের দরকার নেই)
4. Deploy → Manage deployments → ✏️ (Edit) → Version: **New version** → Deploy
5. একবার রিডিপ্লয় করলেই যথেষ্ট — URL পরিবর্তন হবে না

## ধাপ ১ — GitHub রিপোজিটরি তৈরি
1. github.com এ লগইন করুন → নতুন একটা রিপোজিটরি তৈরি করুন (public বা private, দুটোই চলবে, তবে GitHub Pages ফ্রিতে চালাতে হলে **public** হতে হবে, অথবা GitHub Pro/Team থাকলে private-ও চলবে)।
2. রিপোজিটরির নাম যা খুশি দিন, যেমন `cash-manager`।

## ধাপ ২ — ফাইল আপলোড
1. রিপোজিটরির পেজে "Add file" → "Upload files" চাপুন।
2. `index.html` ও `bundle.min.js` — দুটো ফাইলই ড্র্যাগ করে ছেড়ে দিন।
3. "Commit changes" চাপুন।

## ধাপ ৩ — GitHub Pages চালু করা
1. রিপোজিটরির উপরে "Settings" ট্যাবে যান।
2. বাম পাশে "Pages" এ ক্লিক করুন।
3. "Build and deployment" → Source: **Deploy from a branch**।
4. Branch: **main** (অথবা যেটা আছে), Folder: **/ (root)** নির্বাচন করে Save করুন।
5. কিছুক্ষণ পর (১–২ মিনিট) একটা লিংক দেখাবে, যেমন:
   `https://<আপনার-ইউজারনেম>.github.io/cash-manager/`

এই লিংকই আপনার লাইভ অ্যাপ — যেকোনো ব্রাউজার/ডিভাইস থেকে এটা দিয়ে ঢুকতে পারবেন।

## পরবর্তী আপডেট
পরে কোনো পরিবর্তন হলে শুধু নতুন `index.html` / `bundle.min.js` দিয়ে পুরনো ফাইল দুটো ওভাররাইট (রিপ্লেস) করে commit করলেই GitHub Pages কিছুক্ষণের মধ্যে নতুন ভার্সন দেখাবে।

## মনে রাখবেন
- এই অ্যাপ ডেটা সংরক্ষণ করে আপনার Google Sheet-এ, Apps Script এর মাধ্যমে। GitHub শুধু ফাইলগুলো হোস্ট করছে, ডেটা এখানে থাকে না।
- `ACCESS_KEY` ইতিমধ্যে `bundle.min.js`-এ বসানো আছে — এটা রিপোজিটরি public হলে টেকনিক্যালি যে কেউ ফাইল ডাউনলোড করে দেখতে পারবে। তাই:
  - সম্ভব হলে রিপোজিটরি **private** রাখুন (GitHub Pro দরকার হতে পারে private repo থেকে Pages চালাতে), অথবা
  - রিপোজিটরি public রাখলেও সমস্যা নেই যদি আপনি নিয়মিত `ACCESS_KEY` পরিবর্তন করেন এবং শুধু বিশ্বস্ত মানুষকে অ্যাপের লগইন (Admin/Manager/Cashier পাসওয়ার্ড) দেন — কারণ অ্যাপে ঢোকার জন্য এখনো লগইন পাসওয়ার্ড লাগবে।
